# lab-classes

Starter code for the **Classes (User & Tweet)** lab in *CSCI 40: Computing for the Web*.

![doctests](https://github.com/rtealwitter/lab-classes/actions/workflows/doctests.yaml/badge.svg)

Fork this repository, clone your fork, then fill in the function bodies in
`lab_classes.py` until the doctests pass:

```bash
python -m doctest -v lab_classes.py   # every test OK (silent without -v) means success
```

Push your fork and the **doctests** badge above turns green once every test
passes. Submit your fork's URL on Gradescope, resubmitting until it is 100%.
